Feature request 4: weekly bookings.

- `book ROOM ... --repeat weekly --count N`, with N from 2 to 52, creates N bookings: the given one, and the same times on each of the following weeks. `--repeat` without `--count`, or the reverse, or another value than `weekly`: exit 1.
- All or nothing: when any occurrence would be invalid or in conflict, no booking is created, and the exit code is the one a single booking would get (1 before 2, as always).
- It prints the array of created bookings in date order. They share a `series` field, an integer series id. The first series gets id 1, the next one 2, and so on; this counter is separate from booking ids. A booking made without `--repeat` has `"series": null`.
- `cancel --series S` cancels every booking of series S that is not cancelled yet, and prints them as an array. An unknown series, or a series with nothing left to cancel: exit 1.
- `cancel ID` on one occurrence cancels only that occurrence.
