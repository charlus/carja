Feature request 5: opening hours.

- `room hours ROOM --open HH:MM --close HH:MM` sets the room's daily opening hours, the same every day. Open must be before close. `24:00` is valid for close only. Anything else: exit 1. It prints the room, which now shows `open` and `close`.
- A room whose hours were never set is open from `00:00` to `24:00` and shows those values.
- Every new booking, including each occurrence of a weekly booking, must lie within the room's hours: start at or after open, end at or before close. Else exit 1.
- Changing the hours does not change or remove existing bookings.
