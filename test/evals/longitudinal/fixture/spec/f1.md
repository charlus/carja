Feature request 1: rooms.

- `room add NAME --capacity N` creates a room. NAME is case-sensitive, 1 to 40 characters. N is an integer of at least 1. It prints the room as an object with at least `name` and `capacity`.
- A room with the same name already exists: exit 1. A missing or invalid capacity: exit 1.
- `room list` prints the array of rooms, sorted by name.
- Rooms persist between commands.
