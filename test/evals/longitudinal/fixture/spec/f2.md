Feature request 2: bookings.

- `book ROOM --start TIME --end TIME --who NAME [--people N]` books a room. `--people` defaults to 1. It prints the booking as an object with at least `id`, `room`, `start`, `end`, `who`, `people`.
- Booking ids are integers. The first booking gets id 1, and each new booking gets the next one. An id is never reused.
- Rules: an unknown room is exit 1. The end must be after the start, on the same calendar day, else exit 1. People must be between 1 and the room's capacity, else exit 1. A booking that overlaps an existing booking of the same room is exit 2. Times are half-open intervals: a booking that ends at 10:00 does not overlap one that starts at 10:00.
- `bookings [--room ROOM] [--day DATE]` prints the array of bookings, sorted by start, then by id. The two filters can be combined. `--day` selects the bookings that start on that date.
