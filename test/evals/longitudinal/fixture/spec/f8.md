Feature request 8: renaming and the daily report.

- `room rename OLD NEW` renames a room and prints it. NEW must not exist already (exit 1); an unknown OLD is exit 1. Afterwards, every booking, waiting request, series and invoice line of the room shows the new name, and every command accepts the new name.
- `report --day DATE` prints an array with one object per room, sorted by room name: `{"room", "booked_minutes", "open_minutes", "utilisation"}`. `booked_minutes` counts the minutes of the confirmed bookings of that day. `open_minutes` is close minus open, in minutes. `utilisation` is booked_minutes ÷ open_minutes, rounded to 2 decimals, as a JSON number.
